## 사진 출처와 이용 조건

- 작품: **Prayer meeting, Pyeng Yang, [s.d.]** — 평양의 정기 기도회 기록사진.
- [Wikimedia Commons 원문·라이선스](https://commons.wikimedia.org/wiki/File:Prayer_meeting,_Pyeng_Yang,_(s.d.)_(Taylor_box21num64).jpg)
- [원본 JPEG 다운로드](https://upload.wikimedia.org/wikipedia/commons/f/fc/Prayer_meeting%2C_Pyeng_Yang%2C_%28s.d.%29_%28Taylor_box21num64%29.jpg)
- [USC Digital Library 원소장 기록](https://digitallibrary.usc.edu/cdm/ref/collection/p15799coll48/id/761)
- 촬영자 표기: Methodist Episcopal Church.
- 소장: The Reverend Corwin & Nellie Taylor Collection / USC Korean Digital Archive.
- 기록상 연대: **1908–1922**. 정확히 1907년의 집회나 장대현교회 사진이라고 표기하지 않는다.
- 이용 조건: Commons에서 **Public domain**으로 표시한 사진. 근거 태그는
  `PD-Japan-oldphoto`, `PD-1996 (with a reason)`이다. Commons의 설명문 라이선스와 사진의 이용 조건을 구분한다.
- 저장 파일: `public/images/pyeng-yang-prayer-meeting.jpg` — 원본 전체 구도를 유지해
  2000 × 1472로 축소·최적화한 JPEG, 426,671 bytes.

사진 처리는 크롭, 남색·따뜻한 미색 듀오톤, 비네트와 문자 뒤 명암 조정으로 제한했다.
원래 사진의 인물·건축·질감을 유지하며, 생성형 이미지, 합성 인물, 가짜 구름·광선·발광이나
추가 입자 효과를 사용하지 않았다.

행사명·날짜·장소·주제는 제6차 Again 1907 평양대부흥회,
2027.01.25(월)–01.30(토), 오산리기도원,
주님이 역사하시는 초자연적 부흥집회, 호세아 6:1로 유지한다.

인원이 바뀌면 생성 스크립트가 중단되므로 강사 행의 배치도 함께 검토해야 한다.

## 다시 생성하기

문구와 배치는 `scripts/generate-event-artwork.py`에서 수정한다.

```sh
python -m pip install fonttools pillow
python scripts/generate-event-artwork.py
```

모든 SVG·WebP·PNG를 한 번에 생성한다. 기존 `--png` 옵션도 호환되지만 이제 별도로
지정할 필요가 없다. 저장된 사진과 `public/fonts/`의 글꼴만 사용하므로 생성 시
브라우저나 네트워크가 필요 없다. Python·fontTools·Pillow는 제작 도구이며 Next.js의
빌드·실행 의존성은 아니다.

SVG에는 사진과 WOFF 글꼴 서브셋이 내장되어 별도 파일 요청 없이 표시된다.
기존 Nanum Myeongjo·Playfair Display 기반 글꼴을 유지하며, 출처와 SIL Open Font
License 1.1은 `public/fonts/SOURCES.txt`, `NanumMyeongjo-OFL.txt`,
`PlayfairDisplay-OFL.txt`에 있다. 소셜 미리보기는 호환성이 높은 PNG를 사용한다.

검증 중 `npm run build`는 컴파일 성공 후 TypeScript 작업자 생성 단계에서
샌드박스의 `spawn EPERM`으로 중단되었다. 전체 프로덕션 빌드 통과로 간주하지 않으며,
배포 전 로컬 환경에서 빌드를 완료해야 한다.

이미지 디코딩·규격·용량, SVG XML 및 내장 사진, 앱의 참조 경로를 확인했다.
포스터·공유·주제 이미지를 직접 보고, 포스터는 336px 축소본에서도 제목·날짜·장소를
확인했다. 브라우저 연결 호스트를 사용할 수 없어 실제 모바일·데스크톱 페이지의
브라우저 검증은 완료하지 못했다. 기존 반응형 레이아웃과 HTML 주제 문구는 유지했다.
